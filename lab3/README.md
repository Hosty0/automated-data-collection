# Инструкция по воспроизведению

**Переменные окружения:** 
Для работы обоих пайплайнов (Python и n8n) настройка `.env` и API-ключи не требуются.

## 1. Запуск пайплайна

Откройте `lab3.ipynb` и выполните все ячейки сверху вниз (кнопка **Run All**). Данные сохранятся в локальные файлы `data_clean.csv` и `data_raw.jsonl`.

## 2. No-code пайплайн (n8n)

**Команда для запуска (предварительно должен быть установлен node.js):**
```bash
npx n8n
```

**Выполнение:** 
1. Откройте `http://localhost:5678` в браузере.
2. Создайте новый workflow и импортируйте файл `workflow.json`.
3. Откройте настройки финального узла `Read/Write Files from Disk` и проверьте путь сохранения файла.
4. Нажмите **Test Workflow**. Результат сохранится в файл `nocode_result.csv`.
